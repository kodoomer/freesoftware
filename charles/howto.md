**tested only on v5.0.3**

0. close charles
1. go into the install directory (for me `C:\Program Files (x86)\Charles`)
2. open the `lib` folder
3. un**zip** `charles.jar` into `charles` (i used 7-zip)
4. delete `charles.jar`
5. open the `charles/com/charlesproxy` folder
6. replace `myLN.class` with the one from this repository
7. go back to the `charles` folder (in `lib`)
8. archive everything into `charles.zip` (i used 7-zip once again)
9. rename `charles.zip` into `charles.jar`
10. move to `lib`
11. enjoy no 5 second banner
---
if youre paranoid you can use [recaf](https://github.com/Col-E/Recaf) to check what has been changed
